Good to know

Frequently asked questions

What is Catch-Hub? +

Catch-Hub is an unofficial, student-built GPS tag game inspired by Jachtseizoen. It brings groups together for a live chase.

How does a game work? +

One group hunts while the other runs and hides. Hunters follow the fugitives on a live radar as the chase unfolds.

How do we get started? +

Start a session from the button at the top of this page. Sessions use a code to get your group into the game.

Is Catch-Hub an official Jachtseizoen product? +

No. Catch-Hub is an independent school project made by students, inspired by the chase-game format.
